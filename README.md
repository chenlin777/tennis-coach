# Tennis Coach

把教练分析网球视频时的观察、判断和教学建议，逐步做成可以使用、检查和改进的开源软件。

项目由网球教练的实际教学方法主导，结合经过验证的其他经验。我们先明确教练怎样判断，再选择合适的计算机视觉和机器学习方法。

## 当前状态

已有可运行的本地视频隐私预处理原型：一键分析人脸与头部、随运动自动遮盖、慢放检查、手动画框补充、可选环境像素化、导出静音副本。采用 MediaPipe 人脸检测与姿态跟踪，视频在浏览器本机处理。自动处理可能漏遮或多遮，导出前仍需检查。

当前姿态模型用于辅助定位头部，尚未实现教学动作判断或评分。

## 启动隐私预处理

Windows 用户需要 Python 3 和近期版本的 Edge 或 Chrome。

1. 首次使用自动模式：双击 `setup-auto.cmd`，下载经过校验的模型与浏览器运行库。仅此步骤需要联网。
2. 双击 `start-privacy.cmd`，打开本机页面。保持启动窗口运行，结束时关闭窗口即可。
3. 选择本机视频，保持默认的“自动跟随遮盖”，点击“一键分析并跟随遮盖”。
4. 播放检查；需要时补画遮盖区，或单独开启环境像素化。
5. 导出并下载静音 WebM 副本。导出时保持页面在前台，耗时约等于视频长度。

也可以在项目目录运行：

```powershell
python scripts/setup_auto.py
python serve.py --open
```

Python 服务和安装器只依赖标准库；模型通过浏览器 WebAssembly 在 CPU 上运行，无需安装 Python 机器学习包或配置显卡。下载资源保存在被 Git 忽略的 `web/vendor/`。未安装模型时，仍可选择手动处理或不处理。若默认端口被占用，可运行 `python serve.py --port 8766 --open`。

脸部与环境可以分别选择“不处理”。自动头脸遮盖会随时间移动；手动补充框和环境保留框仍是固定区域。环境保留框内的背景仍然可见。原片不修改，视频不上传。

详见 [隐私处理说明](docs/PRIVACY.md) 与 [自动处理规则及开源选型](docs/AUTO_PRIVACY.md)。

## 第一版目标

从固定机位拍摄的正手练习视频开始，完成一个小而完整的流程：

1. 导入视频，播放、慢放并定位关键帧。
2. 由教练标记击球阶段，以及一个优先改进的问题。
3. 将观察到的事实、判断理由、适用条件和练习建议关联到视频片段。
4. 逐步加入人体姿态识别，辅助教练查看和修正。
5. 在教练确认的案例上验证自动判断，再比较练习前后的表现。

第一版范围是起点；具体分析项目由真实教学案例决定。

## 如何开始

教练可以挑一段自己熟悉的正手视频，像给学员上课一样讲解：看到了什么、为什么值得调整、先改什么、怎么练，以及如何看出改善。无需编程，也无需提前整理成技术格式。

- [教学案例模板](docs/COACHING_CASE_TEMPLATE.md)：把一次讲解整理成可讨论的案例。
- [开发路线](docs/ROADMAP.md)：从第一份案例到可运行原型。

本地真实视频与教学记录放在 `local/`。例如：

```text
local/
  videos/          原始视频
  coaching-cases/  真实教学记录
  outputs/        分析输出
```

`local/` 已被 Git 忽略，默认不会随代码推送到 GitHub。公开示例另行选择并确认授权。

## 分析原则

- 区分视频中观察到的事实、教练的解释和待验证的假设。
- 每条反馈能够追溯到具体片段、教学规则及其适用条件。
- 保留教练修正和“看不清／无法判断”的入口。
- 职业选手视频用于提供参考；动作相似度不直接作为技术好坏的标准。
- 人体姿态模型输出是估计值，不自动等同于真实视线、握拍、三维关节角或发力情况。
- 每次优先给少量可执行反馈，并用后续视频和击球表现检验效果。

## 开发检查

静态服务检查不需要第三方依赖：

```powershell
python -m unittest discover -s tests -p test_server.py -v
```

浏览器测试使用 `requirements-dev.txt` 中的开发依赖和本机 Edge，测试素材为程序生成的合成视频，不使用真实学员视频：

```powershell
python -m pip install -r requirements-dev.txt
python -m unittest discover -s tests -v
```

自动模式的界面测试使用明确的模拟检测结果，验证取消、切换文件、检查提示和动态遮盖导出；另有真实遮盖时间轴函数测试。这些测试不衡量模型识别准确率。模型效果需另外用本机视频验证，私人视频和验证输出不进入公开仓库。
