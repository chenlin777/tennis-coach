# 教练案例空白模板

从一段正手视频、一个你最想解决的问题开始。你可以直接口述下面的问题，由助手整理；不需要懂代码，也不必一次答完整。暂时不能确定的地方，写“暂不确定”即可。

这份文件是供开源使用的空白模板。实际案例请复制到 `local/` 下填写，真实视频和学员记录也放在 `local/`；不要在这份公开模板里填写姓名、联系方式、可识别的视频链接或其他学员信息。
