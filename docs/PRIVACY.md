# 视频隐私预处理

## 用户选择

用户在本机选择视频、分析和预览，再决定是否导出。当前没有上传或分享接口，选择文件不会把视频传给服务器。脸部默认“自动跟随遮盖”，环境默认“不处理”；两者均可单独关闭。

| 选项 | 当前行为 | 使用时需要知道 |
| --- | --- | --- |
| 头脸自动跟随 | 一键扫描人脸与头部，按时间移动不透明遮盖框 | 可能漏检、跟丢或多遮；不能替代完整检查 |
| 手动脸部遮盖 | 拖动画出一个或多个固定遮盖区 | 不随运动移动；也可在自动模式中补充遮盖 |
| 脸部不处理 | 保持原始头脸画面 | 导出仍为静音 WebM |
| 环境像素化 | 手动画出保留区，框外像素化 | 框内背景仍可见；框外的球和球拍也可能变模糊 |
| 环境不处理 | 保持背景 | 场地线索仍可见 |

自动模式需要先完成当前视频的分析。完全没有检测结果时，提示改用手动模式；部分时间段没有检测结果时，提供跳转检查和复核选项。**检测到了框，不等于框一定覆盖正确的人脸；没有提示，也不等于整段没有漏遮。** 当前检查提示无法判断多人场景中是否漏掉某个人。

切换视频、取消分析或分析失败，不会把未完成结果当作新视频的成功结果。手动模式开启却没画框、环境处理开启却没画保留区时，不能导出。导出文件不包含编辑边框，使用 `-privacy-silent.webm` 后缀，不覆盖原片。

## 在本机运行

首次运行 `setup-auto.cmd` 从固定来源下载运行库和模型，校验文件后保存在 `web/vendor/`。安装器不读取用户视频。以后使用时，网页只从本机加载这些资源，推理在浏览器内进行。

处理流程：本机文件 → 浏览器内的视频与模型 → 处理画布 → 本机下载。

- Python 服务监听 `127.0.0.1`，只提供明确列出的网页、运行库和模型文件，不开放仓库目录或 `local/`。
- 网页不使用外部字体、CDN、分析统计、上传接口或远程推理服务。内容安全策略允许本机资源和 WebAssembly，限制页面外联。
- 视频与检测结果不写入浏览器持久化存储。关闭页面释放处理状态；用户下载的文件留在所选位置。
- 导出不添加原片音轨，避免把声音一起分享。重新编码画布，不复制原文件的附加元数据。
- 遮盖脸部不等于完全匿名：衣着、身形和场地仍可能具有辨识度。

未来若增加远程分析，应明确展示待上传的版本、保留期限和删除入口，并只上传用户确认的文件。当前没有远程流程。

## 与教学分析的关系

隐私处理不能制造本来不可观察的证据。遮住眼睛后，视线相关项目应显示“无法判断”，不能按未达标计分。背景处理应尽量保留完整身体、球拍、球路和必要的地面参照。

当前没有使用人物分割自动删除整个背景，因为仅保留人体可能同时抹掉球、球拍与场地线索。将来可以先在本机分析原片，再生成用于分享的打码版本；这尚未实现。当前模型仅用于隐私定位，没有教学动作判断或评分。

## 当前限制

- 自动分析每秒采样约 10 帧，使用人脸检测、姿态跟踪与短时间间隔的补遮。侧脸、背身、遮挡、远处小脸及快速移动仍可能失败；背景也可能被错认成人脸。
- 手动补充框作用于整段视频，目前不能按时间段修改自动框。误遮严重时，可选择手动模式重新画框。
- 推荐近期版本的 Edge 或 Chrome；需浏览器能解码输入视频，并支持 Canvas、WebAssembly 和 MediaRecorder。
- 自动分析与导出时保持页面前台；转入后台会取消当前操作。可以取消后重试。
- 导出按正常速度实时录制，耗时约等于视频长度。大文件占用内存，建议先用短片段。
- 保持输入画面尺寸，目标录制帧率 30 fps；实际帧率取决于设备。输出重新编码，不承诺逐帧无损或保留高帧率慢动作。

完整播放处理结果，并检查最终导出文件，尤其留意转身、交叉遮挡和进出画面的时刻。

## 开发验证

服务测试检查私有路径不可访问、静态文件白名单和内容安全策略。合成视频测试检查遮盖、环境保留、静音导出、取消及网络请求；自动界面测试使用模拟检测结果，另有真实时间轴函数测试。模型效果必须另做实际视频验证，不能用界面测试通过代替识别准确率。

实现与来源见 [自动处理规则](AUTO_PRIVACY.md)、[Canvas captureStream](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/captureStream) 和 [MediaRecorder](https://developer.mozilla.org/en-US/docs/Web/API/MediaRecorder)。
