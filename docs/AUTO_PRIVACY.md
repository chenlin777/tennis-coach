# 自动头脸遮盖

目标是让用户一键得到可检查的遮盖结果，减少逐帧画框。定位脸与头部即可完成这项任务，不需要识别人物身份。

## 默认规则

1. 本机读取视频，每秒约采样 10 帧，分析宽度不超过 1280 像素。
2. 使用 BlazeFace Full Range 检测人脸，使用 Pose Landmarker Lite 的视频模式跟踪身体并估计头部范围。姿态模型最多检测 4 人，但没有验证拥挤场景的覆盖能力。
3. 扩大检测框，给侧脸、头顶和相邻帧之间的移动留出余量。合并重叠框，按邻近位置关联时间轴。
4. 对同一轨迹间隔不超过 0.45 秒的相邻结果，遮住两个框的并集；轨迹边缘最多延续 0.12 秒。长时间失去目标时不无限沿用旧位置。
5. 标出没有任何头脸检测结果的采样时段，供跳转检查。该提示不能检测所有跟踪错误或漏掉的旁人。
6. 预览和导出使用同一份完成的分析结果，并叠加用户手动补充的固定区域。最终导出不包含声音。

规则目前写在 `web/auto_privacy.js`，用户无需调参数。默认选择自动头脸遮盖、环境不处理。此预设不声称自动识别所有隐私信息：文字、车牌、衣服标识和场地位置不在当前自动检测范围内。

## 开源选型

采用 [MediaPipe](https://github.com/google-ai-edge/mediapipe) 的浏览器接口，让模型在已有的本地网页中运行。运行库版本固定为 `@mediapipe/tasks-vision` 1.0.1，模型 URL 固定到版本 1。下载来源、完整性校验和许可证见 `scripts/auto_assets.json` 与 [第三方声明](../THIRD_PARTY_NOTICES.md)。

接口依据：

- [Face Detector Web 文档](https://ai.google.dev/edge/mediapipe/solutions/vision/face_detector/web_js)
- [Pose Landmarker Web 文档](https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker/web_js)

也评估了 [deface](https://github.com/ORB-HD/deface)，它提供基于 CenterFace 的本地人脸匿名化命令行工具，适合后续批处理路线。当前没有引入 deface，主要是为了沿用浏览器本地预览、人工补框和导出的流程。

## 已知取舍与后续工作

扩大框和短间隔补遮能减少边缘露出，也可能挡住手臂、球拍或较多背景。错误的人脸候选可能产生多余遮盖。检测框出现在每个采样时刻，只说明模型持续产生了候选，不能解释成全片保护率。

目前测试覆盖界面状态、动态遮盖导出、短缺口补遮、长缺口、多人轨迹和视频边界；模型效果仍需用不同距离、光照、转身、多人和快速运动的视频独立评估。私人素材与检查截图不进入公开仓库。

下一步优先支持按时间段修正自动框、删除误检，以及标记异常轨迹。环境自动处理需要同时保留人体、球拍、球路和教学所需参照，再决定分割与遮盖规则。
